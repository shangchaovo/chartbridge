# 绘图颜色面板与默认色保存（2026-10-20）

本轮根据用户提供的界面截图，将浮动绘图工具栏的浏览器原生颜色入口替换为页面内色板，并加入红、绿快捷色块。界面采用与现有图表一致的 TradingView 风格；本轮未读取原站源码，也未声明与原站全部调色行为完全等价。

## 使用方式

- 选中图形后，工具栏显示当前颜色，以及红色 `#f23645`、绿色 `#089981` 两个快捷色块。点击快捷色块立即更新当前图形。
- 点击当前颜色打开色板，提供 80 个预设色、最近使用的颜色、自定义饱和度/亮度、色相、HEX 和 RGB。
- 主动选色后，最后选色立即保存到当前浏览器的 `shanhai-drawing-colors`。新建图形、切换工具和刷新页面后沿用它；点选已有图形、撤销改色或只调整线宽不会重写个人默认色。
- 初次使用且尚未主动选色时，保留各工具自身的初始颜色和线宽，包括荧光笔的黄色和较粗笔迹。
- 绘图设置窗口复用同一色板；取消丢弃草稿，确定才应用图形样式和个人颜色偏好。
- 矩形背景与边框同时跟随所选颜色；其他常规图形、曲线和画笔沿用各自渲染方式。
- 支持明暗主题、窄屏约束、点击外部关闭、Esc 关闭颜色面板及键盘操作。只读访问者的改色按钮禁用。
- 补齐图形点击回调，解决撤销后图表仍保留内部选择、浮动工具栏却隐藏时，再点同一图形无法重新显示工具栏的问题。

## 实现与验证

- `src/drawing-colors.js`：默认色和最近使用颜色的读取、校验与保存，以及颜色转换和图形样式合并。
- `src/color-picker.js`：可复用的颜色控件；用于浮动工具栏及绘图设置窗口。
- `src/main.js`、`src/drawing-editor.js`、`src/style.css`、`index.html`：新建图形、选中图形、设置保存和布局的接入。
- `tests/drawing-colors.test.mjs`：新增六项测试，覆盖刷新恢复、最近颜色去重与容量、损坏或不可用存储、样式保留、RGB/HSV 转换及矩形填充。

最终 `npm test` 为 224 项通过、0 失败；`npm run build` 和 `git diff --check` 成功。

浏览器验收使用独立 Chromium、端口 18770 和独立数据目录，不修改用户正在使用的工作区。行情来自已有真实 OHLCV 缓存，目录响应使用项目内置目录，实时流静默，避免上游网络影响可重复验证。浏览器验收覆盖十组场景：快捷改色、新图形和连续绘图继承、旧图形选择、刷新恢复、色板及撤销、HEX/RGB/HSV、设置保存和取消、明暗主题与 390px 窄屏、只读模式、损坏偏好恢复。浏览器运行错误和绘图保存失败均为零。
