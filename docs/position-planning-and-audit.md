## 使用多空仓位

1. 左侧选择工具下方，展开「多空仓位 · 盈亏比」，选择多头或空头。
2. 在主图的**入场位置点击一次**，生成默认 `1:1` 仓位。多头止损在入场下方，空头止损在入场上方。
3. 左侧上、下手柄分别调整止盈和止损，中间手柄调整入场；右侧中间手柄只调宽度，拖动框体整体平移。双击仓位框，或选中后点击浮动工具条的设置图标，进入「输入 / 样式」窗口。
4. 输入资金、风险百分比或固定风险金额，自动反算数量；也可手动指定数量。`1:1` 至 `1:5` 快捷按钮按止损距离设置止盈价。
5. 在「更多」中可添加止盈和止损两条价格提醒、复制计划或导出 JSON。图形和参数随共享图表保存，支持刷新恢复、复制、显隐、锁定、删除、撤销和重做。最后应用的设置保存在本机，作为下次创建仓位的默认值。

默认只在选中时显示统计和价格标签，点击图表空白处收起；在「样式」中开启「始终显示统计」可保留显示，也可修改区域颜色、透明度、文字大小和统计内容。

位置容易重叠时，可从左侧「图形对象管理」选择仓位名称。定位会把整个图形的横向范围居中。改变多空方向会保留图形 ID；撤销会恢复原方向及参数。

这是图上的交易计划测算。应用、提醒及 Agent 写入均不调用交易所下单接口。

## 数值口径

资金与盈亏按相同计价单位计算。适用于正价格、线性盈亏合约；外汇和期货需自行填写实际乘数和数量步长。

| 参数或结果 | 计算口径 |
|---|---|
| 毛盈亏比 | 入场到止盈的价差 ÷ 入场到止损的价差 |
| 滑点 | 入场、止损和止盈均按所填 bp 计入不利成交偏移 |
| 费用 | 每次成交按名义价值计费，进出两次均计算 |
| 净盈亏比 | 扣除上述费用和滑点后的单位收益 ÷ 单位风险 |
| 自动数量 | 风险预算 ÷ 单位净风险，再按数量步长及数量精度向下取整 |
| 手动数量 | 按数量步长及数量精度向下取整，超出风险预算时显示提示 |
| 杠杆 | 仅影响保证金估算，不扩大自动风险数量 |
| 保证金 | 入场名义价值 ÷ 杠杆，未模拟分档保证金、强平或资金费 |
| 现价盈亏 | 按当前报价假设平仓的估算值，不判断历史上是否先触发止盈或止损 |

例如：资金 10,000、风险 1%、多头入场 100、止损 95、止盈 110、数量步长 1、费用与滑点为 0，得到数量 20、风险 100、收益 200、盈亏比 `1:2`。空头 100 / 105 / 90 的结果对称。反向币本位合约、跨币种换汇、交易税、隔夜成本和真实成交限制尚未建模。Tick 用于距离换算，不代表已向交易所校验价格步长。

## 本轮新增的八个工具

| 工具 | 已实现内容与边界 |
|---|---|
| 多头仓位、空头仓位 | 单击放置、四个独立手柄、盈亏色块与居中标签、毛/净盈亏比、风险预算、数量精度、合约乘数、费用、滑点、保证金估算、参数和样式编辑、计划导出 |
| 信息线 | 两点价差、百分比及实际 K 线索引间隔 |
| 椭圆 | 双锚点绘制和调整 |
| 斐波那契时间区间 | 按两点数据索引距离投射 0、1、2、3、5、8、13、21 倍时间区间 |
| 锚定 VWAP | 从所选 K 线起，按实际 HLC3 和成交量累计加权；回放只读取已显示数据 |
| 线性回归通道 | 区间收盘价最小二乘拟合，中心线、±2 倍残差标准差和 R² |
| 区间量能分布 | 24 个价格分箱、POC 和 70% 价值区；每根 K 线成交量在高低区间均匀分配，标明「K线估算」 |

量能分布不包含逐笔买卖方向，也未使用更小周期重建成交量；不能当作 TradingView 逐价成交量的等价实现。VWAP 的输入仍受当前源成交量、周期与已加载历史范围影响。

## 品种图标

当前内置目录为 307 个品种，另外保留 17 个默认关闭的国内期货条目。全部 324 个条目都有可见标记：256 个使用本地品牌图标，其余使用货币对、商品、指数或彩色文字标记。股票目录的品牌图标均已配置；TON 和 ARKK 等当前未取得品牌资源的条目使用文字标记。分类标记不冒充官方品牌。

- 新增 193 个公开 SVG 资源。不同交易所的同一种币、不同计价币种和股票永续标的复用相应图标。
- 搜索结果、自选列表、品种选择器与主图标题使用同一套映射。`0700.HK` / `00700.HK`、`SH600519` / `600519.SS` 等代码别名也可识别。
- 图标从本机加载，不依赖远程图片服务。加载失败时保留已经绘制的 SVG 标记。
- [资源清单](../src/assets/logos/sources.json)记录下载时间、公开元数据源、原始图片 URL 和 SHA-256。维护者可显式运行 `node scripts/sync-symbol-logos.mjs` 更新；应用启动不执行同步。
