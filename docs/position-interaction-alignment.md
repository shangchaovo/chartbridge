# 仓位工具的交互调整

2026-10-17，针对“使用不顺手、希望与 TradingView 保持一致”的反馈，按[官方仓位说明](https://www.tradingview.com/support/solutions/43000517002-long-position-drawing-tool/)及[官方教程 01:13–01:45](https://www.youtube.com/watch?v=OGF0K1UIUcs&t=73s)调整主要交互。

| 操作 | 当前行为 |
|---|---|
| 放置 | 选择多头或空头，在入场位置点击一次，生成默认 `1:1` 仓位框 |
| 止盈 / 止损手柄 | 左侧上下两个方形手柄只改对应价格，横向偏移不改变宽度 |
| 入场手柄 | 左侧中间手柄调整入场位置，保留已有止盈、止损价格；不允许跨过两者 |
| 宽度手柄 | 右侧中间手柄只改横向长度，上下偏移不改变价格或盈亏比 |
| 框体 | 拖动整个仓位，保持止盈和止损价差；拖动时立即选中 |
| 选中与标签 | 目标、浮动盈亏/数量/风险回报比、止损三块标签居中。默认仅选中时显示；点空白处收起 |
| 参数窗口 | 双击框体，或点击浮动工具条的设置按钮，打开「输入 / 样式」两页窗口 |
| 窗口操作 | 固定底部的取消、确定按钮；取消不改已保存计划，手机窄屏无需滚到底部找确认按钮 |
| 输入 | 资金、手数/步长、风险、入场价、杠杆、止盈和止损的 Tick/价格、数量精度、风险回报快捷比例 |
| 样式 | 线条、止盈止损颜色、透明度、文字、价格标签、紧凑统计、始终显示统计、统计内容 |
| 扩展功能 | 费用、滑点、合约乘数和手动数量放在折叠区；复制、导出、提醒和默认模板放在「更多」菜单 |

数量计算同时满足数量步长与所选小数精度，并向下取整；例如 `.03` 的步长、1 位小数，实际可用的最小增量是 `.3`。默认 `3` 位显示；旧参数若使用更细步长，会补足所需精度，最多支持 12 位。

旧的三个价格锚点存储格式继续保留。恢复、撤销、重做或样式修改不会重新生成默认价格；已有参数中缺少的新样式字段使用默认值。旧价格的额外小数不会因只改样式而被截断。图表外观设置仍按已有线性、对数和百分比轴投射。

## 观察来源及范围

官方教程说明单击放置默认仓位、再调止盈/止损/横向长度和双击设置；公开帮助图片及文字给出输入、颜色、统计和“仅选中时显示”的设置。

独立匿名浏览器中，正确点击工具图标后，公开 TradingView 当前显示注册/登录提示。REA 的六个步骤完成并清理浏览器，但本轮没有在登录后的原版上完成鼠标放置和数值对比。最新证据摘要见 [REA 交互观察](rea-position-interaction-2026-10-17.json)。最初的菜单行中心点击实际命中嵌套帮助按钮，旧摘要已据此更正。

这些修改对齐主要操作与信息布局，不声明逐像素、全部数值或全部功能等价。框中显示按当前报价估算的浮动盈亏，不模拟历史上止盈止损先后成交；仍不发送交易订单。完整计算范围与其他缺口见 [仓位计算与补齐清单](position-planning-and-audit.md)。
