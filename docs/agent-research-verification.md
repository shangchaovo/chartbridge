# 山海 0.4 · Agent 计算与共享验证

本轮范围：默认停用国内期货与账户行情，继续其他市场，并接通局域网 Agent 的指标计算、基础回测和共享批注流程。未删除既有账户配置、源码、虚拟环境或正式研究数据。

## 自动验证

80 项 Node 自动测试通过，包含原有 66 项和新增 14 项。执行命令为 `node --test --test-reporter=dot tests/*.test.mjs`。静态资源构建、主要模块语法检查、普通本机/局域网启动器语法检查通过。

新增用例验证真实 PineTS 0.11.1 下 SMA/EMA/RSI/MACD/ATR/BB 的已知数值；预热不足保留 null；不把很小的指标值显示成零；完整样本计算不受返回 tail 大小影响；下一开盘成交和双边费用/滑点；收盘未知的末根被排除；源缓存与收盘推定警告；参数/数量边界和自定义代码拒绝；并发上限、任务失败后的释放、工作线程超时终止和提前退出；默认市场范围与保留的可选旧适配器。

单元测试的合成输入只用于验证数学与边界，没有写入正式行情数据，也没有作为真实行情向界面展示。

## 真实网络与 Agent 接口

隔离测试服务 18769 上的 11 项 API/MCP 检查通过：默认目录 47 个品种、国内期货的历史/报价/SSE/账户请求明确停用、自定义代码拒绝、MCP 协议握手与角色工具表、真实行情载入、只读计算、共享批注权限与来源、MCP/REST 市场范围一致，以及真实加密推送。

实网分别取得 BTCUSDT、AAPL、0700.HK、600519.SS、EURUSD=X、GC=F、^GSPC 的 800 根日线，覆盖加密、美股、港股、A股、外汇、国际期货和指数。来源分别为现有 Binance、Yahoo 和新浪公开端点，没有使用价格替身。BTCUSDT 指标计算和 AAPL 基础回测由实际下载数据完成；AAPL 结果保留收盘状态推定说明。

Binance WebSocket 实际收到带源时间的 ticker，测试时 fresh 为 true。这仅验证当次加密源链路，不代表所有市场都已有交易所实时流或全部代码与周期均可用。

官方 MCP Client 2.3.1 使用真实 LAN 地址分别验证 reader/editor 指标工具；随附无依赖 Node 示例分别完成只读回测和编辑凭据发布计算批注。reader 有 9 个查询/计算工具，editor 额外有 1 个共享修改工具。测试中没有打印或导出实际连接凭据。
