# 历史可选账户行情接入 · 山海 0.3

> 国内期货账户桥默认关闭。恢复时设置 `TERMINAL_DOMESTIC_FUTURES=1` 后重启。它不是交易所持仓密钥工作流。

公开免费行情继续可用。本轮准备了 TqSDK 国内期货账户配置、行情桥和接入接口；没有账户时可以保存设置，不发起登录。真实账户认证和数据权限尚未实测。

## 现在可以做什么

在主机 http://127.0.0.1:18765/ 打开「账户行情」：

1. 选择是否启用，填写订阅合约，最多 8 个。主连示例 `KQ.m@SHFE.rb`，固定合约示例 `SHFE.rb2701`。具体合约必须在使用时有效。
2. 选择周期与历史条数。当前支持 1/5/15/30 分钟、1 小时和日线，每组最多 1000 根。
3. 点击「保存配置」。没有账户、没有凭据也可以保存；界面分别显示凭据、运行环境和行情接收状态。

配置保存在本机 `data/market-accounts.json`，其中只有平台、开关、合约、周期、条数和凭据环境变量名称。账户密码不进入此文件、个人工作区、共享图表、导出 JSON 或 MCP 返回值。

「账户行情」只在 localhost 页面提供设置和连接操作。局域网读写凭据均不能读取或修改账户配置，也不能替主机发起登录；其他电脑仍可读取接入后的行情。

## 有账户后如何连接

本机的 TqSDK 3.10.2 可选环境已准备并验证可导入，当前无需重复安装。

1. 关闭原服务窗口（Ctrl+C）。需要重建环境时运行 `scripts/准备天勤行情环境.command`。虚拟环境和包缓存位于项目内的 `.venv-tqsdk/` 与 `.pip-cache/`，二者都不提交。依赖版本固定于 `requirements-tqsdk.txt`。
2. 运行 `scripts/启动账户行情终端.command`。在本机终端输入自己的天勤/快期行情账户与密码。密码输入不回显，只传给本次服务及行情子进程，不写入配置文件。
3. 回到 localhost 页面的「账户行情」，保存并启用配置，点击「连接账户行情」。收到有效数据后才显示「已读取行情」。凭据缺失、环境缺失和连接失败会分别显示。
4. 搜索 `TQ:`，选择配置的独立账户标的，例如 `TQ:KQ.m@SHFE.rb`。图表、双图、SSE 与 MCP 使用这套代码读取账户源；原 `SINA:` 和 Binance 代码继续使用原有公开源。

默认凭据环境变量是 `SHANHAI_TQ_USER` 和 `SHANHAI_TQ_PASSWORD`。进阶部署可以自行在启动服务的环境中提供它们；修改环境后需要重启服务。本终端不会自动保存这些值，也不在重启后自动登录。

账户桥只调用行情相关 API，没有下单或撤单接口。主连/指数保留天勤自身的序列，不把它与新浪连续合约当作相同序列混用。行情历史与实时权限以账户授权为准。

实现依据 [TqSDK 官方快速入门](https://doc.shinnytech.com/tqsdk/latest/quickstart.html) 与 [API 参考](https://doc.shinnytech.com/tqsdk/latest/reference/tqsdk.api.html)：`TqAuth`、`get_quote`、`get_kline_serial`、`wait_update`、`is_serial_ready` 和 `is_changing`。可选 SDK 版本来自 [官方 PyPI 发布](https://pypi.org/project/tqsdk/3.10.2/)。

## 接入接口

- `GET /api/accounts`：已认证客户端可读的非敏感连接状态。
- `GET /api/accounts/config`、`PUT /api/accounts/config`：仅 localhost 管理非敏感配置；配置不接受明文密码字段。
- `POST /api/accounts/connect`、`POST /api/accounts/disconnect`：仅 localhost 发起连接或停止行情桥。
- `/api/catalog`、`/api/search`：启用后包含已配置的 `TQ:` 标的。
- `/api/candles`、`/api/quote`、`/api/stream` 与现有 MCP 行情工具：沿用原接口，传入完整 `TQ:` 代码。

未连接且没有已接收数据时，账户源明确报错，不回退到其他来源冒充账户行情。断开后留在本次内存里的历史可继续读，但标为 stale；尚未把账户历史持久缓存到磁盘。已有公开行情缓存不受影响。

普通 Pine 指标可在账户 K 线上运行。账户市场的跨周期交易日历仍未验证，不宣称完整 Pine 兼容。

Node 自动测试 66 项、Python 桥数据转换测试 3 项通过。新增覆盖配置默认关闭、无凭据保存、密码字段拒绝、连接前置检查、状态与错误脱敏、增量历史合并、断开后缓存标记、配置/连接顺序、TQ 代码保留和普通 Pine 计算。

真实 Python 子进程与 Node 行情管道使用专门的测试 SDK 替身验证，测试数据仅在 `work/`，不作为真实行情展示。浏览器/API 11 项检查通过：公开行情仍可用、账户配置可保存、缺凭据时连接禁用且后端拒绝、局域网账户管理被拒绝、未连接图表明确报错、没有浏览器运行异常。

可选环境按 `requirements-tqsdk.txt` 安装到项目内虚拟环境。未创建真实认证会话前，不要把任何账户输出写进仓库。

这些检查验证接入实现与无账户流程，不代表已经验证真实账户登录、权限或交易时段内连续推送。
