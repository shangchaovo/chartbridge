# TradingView 功能对照与倒计时补齐

核查日期：2026-10-18。对照对象为公开图表和官方说明；本地实现是 KLineCharts / PineTS 上的独立实现。下面按实际代码区分完成度，不将入口存在、REA 步骤执行完毕或单元测试通过视为完整 TradingView 等价。

## 本轮已经补齐

1. **当前 K 线结束倒计时**：默认开启，显示在最新价下方；价格轴右键与图表设置均可关闭。按墙钟每秒刷新，不依赖每秒收到报价。主图、对照图分别使用自己的周期和 K 线，颜色跟随涨跌。采用原生画布图形，PNG 导出包含倒计时。
2. **倒计时语义**：优先使用源提供的 `closeTime`；分钟和小时周期使用实际 K 线起点。连续交易源的日线、周线跟随源 K 线边界；有已知正常交易时段的日线使用源收盘时间。到期直接隐藏，等待下一根真实 K 线，不对过期 K 线循环取模。回放、CSV、离线缓存、暂停更新、已收盘或未来 K 线均隐藏；周期不大于行情延迟时也隐藏。
3. **图表时区**：页脚和设置均可选择 UTC、上海、纽约、伦敦等时区，或跟随交易所；时间轴及十字光标同步，夏令时交由 IANA 时区规则处理。双图按各自交易所解析「交易所时区」。设置保存在本机。
4. **跳转到日期**：页脚日历按钮、时间轴右键提供入口。按当前图表时区定位已加载的实际 K 线，休市缺口定位到下一根；超出加载范围时显示说明。夏令时重复小时优先取时间顺序上的第一次。更早历史仍需先向左拖动加载。
5. **独立的最新价线设置**：可单独控制价格轴标记与横向最新价线。更改时区、倒计时等显示设置不再重置图表右侧空白距离。
6. **数据切换与暂停修复**：更换标的和对照图周期时清空旧数据及计时器；请求按图表实例和请求序号隔离，旧响应不覆盖新选择。取消自动刷新时关闭推送连接，开启时重新连接；倒计时同步更新。收到有效推送后，以新元数据判断缓存状态。
7. **画笔与荧光笔**：左侧几何菜单新增两种自由绘制工具，绘图总数增至 32。按住拖动、松开完成，Esc 取消，支持连续绘制、整体移动、颜色/粗细、锁定/显隐、删除、撤销/重做与保存恢复。用屏幕距离简化笔迹，每条最多 256 个采样点；额外保留 K 线内部的横向偏移，避免细节吸附到 K 线中心。荧光笔保留底图可见。尚无原版画笔的闭合区域背景编辑或跨周期可见性页。
8. **普通绘图编辑器**：双击图形、浮动设置按钮、右键菜单均可打开「样式 / 坐标」。普通锚点可改时间/价格；未来索引锚点可改 K 线索引。保留旧价格与毫秒精度，支持夏令时重复小时，拒绝不存在的本地时间。取消不会提交，锁定时禁用坐标，编辑期间收到其他图形修改时拒绝覆盖。笔迹只提供整体移动与样式，避免把数百个采样点堆进表单。仓位继续使用独立的仓位编辑器。图层顺序现在也随服务端状态保存。
9. **纯折线图**：与面积图分开，可切换和持久保存；沿用真实收盘价序列，不改变回测或指标数据。

计算实现：`src/bar-countdown.js`、`src/chart-time.js`。集成、菜单与双图：`src/main.js`。Yahoo 正常交易时段元数据：`server/market-data.mjs`。

## 本地功能逐项审计

| 范围 | 当前已有 | 仍有差异或缺口 |
|---|---|---|
| 品种搜索与自选 | 本地目录、远程搜索、来源/市场分类、品牌图标、自选增删和排序、导入 | 非全交易所目录；别名、授权及可用周期仍由各行情源决定 |
| 周期 | 1/5/15/30 分钟、1/4 小时、日、周，向左分页加载历史 | 任意周期、秒/Tick/月/季度/年周期未统一接通 |
| 图表类型 | 实心蜡烛、空心蜡烛、OHLC、纯折线、面积 | Heikin Ashi、Renko、Kagi、PnF、Range、Line Break 等尚未实现 |
| 时间与导航 | 平移、缩放、范围按钮、重置、适应全部、回到最新、日期跳转、时区 | 日期跳转目前只定位已加载数据；原版范围按钮对应的周期联动未全部实现 |
| 价格轴 | 线性、对数、百分比、反转、滚轮缩放、双击重置、最新价与倒计时 | 固定价格/K 线比例、多价格轴、全部自动缩放选项未齐 |
| 绘图工具 | 32 种，含画笔/荧光笔、多空仓位、线条、通道、基础斐波那契、几何、文字和区间测量 | 路径/多段折线/弧线，以及完整 Gann/Pitchfork/Elliott/谐波形态未实现 |
| 绘图管理 | 选中、移动、独立仓位手柄、普通图形样式/坐标窗口、复制、层级保存、显隐、锁定、删除、撤销/重做、对象树、持久化 | 尚无原版完整可见周期、填充/扩展等工具专属参数页 |
| 仓位计划 | 多空方向、入场/目标/止损/宽度、输入/样式、风险反算、费用/滑点、保存与导出 | 计划测算，不具备订单修改、持仓同步、真实保证金/强平和历史撮合 |
| 量价绘图 | 锚定 VWAP、回归通道、固定区间量能分布 | 量能分布用 OHLCV 均匀分箱估算；没有原版逐价成交量、Footprint 和买卖主动性数据 |
| 指标 | KLineCharts 内置集合，主图/副图、参数和移除；PineTS 自定义指标 | 与原版指标清单、预热、样式、全部算法和多实例设置不等价 |
| 模板与布局 | 保存布局、最近模板、双图同标的不同周期、可调面板、全屏 | 多模板命名管理、任意多图布局、跨图同步选项和独立标的对比尚未齐 |
| 回放 | 点击起点、前后步进、自动播放、1/2/4/8 倍、隐藏未来数据 | 依赖已加载历史；多市场同步回放与模拟交易撮合未实现 |
| 警报 | 价格触达、单次触发、暂停/恢复、编辑、日志及本机通知通道 | 沿用当前项目的触达语义；未接齐指标/画线条件、频率、组合条件和原版云端提醒 |
| Pine 与回测 | PineTS v5/v6 子集、有限跨标的/高周期请求、EMA/RSI/买入持有基础回测 | 官方 Pine 引擎、动态/低周期请求、全部绘图对象及交易撮合规则仍不完整 |
| 表格与导出 | K 线表格、CSV 导入导出、PNG、JSON 工作区 | 不是原版全部数据窗口、筛选器、完整图表布局/分享协议 |
| 数据与市场语义 | 多源真实 OHLCV、缓存、部分公开推送/轮询与延迟说明 | 完整交易日历、午休/夜盘、复权、换月、合约规格库、全部市场实时授权仍缺 |
| 平台周边 | 本地协作、Agent/MCP、批注 | 新闻、经济/财报日历、热力图、筛选器、社区、券商交易等独立平台模块未复刻 |

## REA 本轮取证情况

实际调用固定版本 `rea-agents 6.5.0` 的 `captureBrowserScenario` 服务及其 Playwright provider，使用自己启动的匿名临时浏览器。原始请求、失败记录、可访问性快照与证据在 `work/rea-features-20261018/`；摘要见 `docs/rea-feature-evidence-2026-10-18.json`。

本轮图表返回了加载进度条及部分图表区域，设置按钮未能完成可重复点击；因此没有取得原版倒计时设置的完整交互证据，也没有对原版计时数值建立一致性结论。直连浏览器出现加载等待，连接模式的默认 service-worker 阻断检查也曾拒绝当前页面。后续使用工具支持的 `service_workers: allow`，独立匿名浏览器通过系统已启用的代理访问；没有修改 REA 本身或现有用户浏览器资料。连接由 REA 释放，启动者负责关闭临时浏览器。

**倒计时规则的当前依据**是 TradingView [官方故障说明](https://www.tradingview.com/support/solutions/43000476233-the-countdown-is-not-displayed-on-the-chart/)、[各周期倒计时公告](https://www.tradingview.com/blog/en/countdown-on-any-time-interval-16488/)及 [Pine 时间说明](https://www.tradingview.com/pine-script-docs/faq/times-dates-and-sessions/)。设置入口、延迟限制和休市隐藏据此独立实现。早前绘图菜单证据仍见 `docs/rea-ui-coverage-2026-10-17.json`，不将历史证据标成本轮重验。

后续通过同一 REA provider 成功取得官方[画笔](https://www.tradingview.com/support/solutions/43000516987-brush-drawing-tool/)、[荧光笔](https://www.tradingview.com/support/solutions/43000791735-highlighter-drawing-tool/)与[矩形](https://www.tradingview.com/support/solutions/43000516984-rectangle-drawing-tool/)帮助文章的可访问性正文及截图。画笔和荧光笔证据 ID 分别为 `ev_c94bacf6bcfe980b3d32fe3fd2ff2f3e0ed9af0f5bfc38522dd21bd8984cac1f`、`ev_26e64fa3cda30242d37731950ff1a0a30840ca8a4b58685f6a85b1a0823b9279`。连接模式的事件部分仍标记缺失，摘要保留原始完整度；帮助内容捕获不作为在原版图表上完成绘制的证明。

## 验证与剩余计时边界

最终自动测试 `npm test`：199 项通过；两组浏览器验收共 23 项通过，未发现页面异常或图形保存失败。`npm run build` 和 diff 空白检查通过。

- `tests/chart-time.test.mjs` 覆盖实际截止时间、秒级变化、到期不循环、日/周边界、延迟阈值、回放/CSV/离线/暂停、交易时段、IANA 时区、夏令时、缺口与历史边界。
- `tests/market-data.test.mjs` 验证 Yahoo 正常交易时段以毫秒保留，同时保持 OHLCV。
- `tests/freehand-editor.test.mjs` 覆盖笔迹简化/上限/横向偏移、服务端保存与层级、坐标编辑原子性、原精度、锁定、夏令时和纯折线类型保存。
- 自由绘制验收：`work/freehand-ui-check.mjs`，记录与截图在 `work/freehand-ui-check/`；覆盖鼠标绘制/拖动、取消、撤销、样式、坐标、保存恢复和 390px 窗口。
- 浏览器验收脚本：`work/features-ui-check.mjs`；结果和截图：`work/features-ui-check/`。使用真实缓存 OHLCV、固定浏览器时钟与明确的开闭盘测试标志，外部推送在该测试中隔离；这是可复现的 UI 验收，不是实时行情或原版等价证明。
- 使用已知截止时间的当前 K 线，不凭本轮工作补造交易日历。非连续市场的周线和没有收盘时间的日线会隐藏倒计时；Yahoo `currentSession` 是正常交易时段，不包含完整历史日历、盘前盘后和所有午休/夜盘段。

剩余实现顺序：路径/多段折线与各工具的填充、扩展等完整参数页；更多图表类型与周期；多模板/多图同步；指标/警报的高级条件；交易日历与完整行情上下文。每项都需要自己的来源证据、交互实现和边界验收。
