使用独立的 `work/position-ui-check-data/` 数据目录及端口 18767。K 线请求使用项目已有的真实历史缓存，公开行情流在页面端固定以便重现。通知发送在验收服务中替换为无外发桩；这里检查价格提醒的创建和去重，不验证通知送达。

`node work/position-ui-check.mjs` 检查：

- 用鼠标完成多头和空头三点绘图，验证价格方向。
- 价格输入、风险数量、盈亏比快捷按钮、费用与滑点、杠杆只改变保证金、手动超预算提示。
- 真实鼠标拖动控制点后更新价格，撤销及重做保留参数。

- JSON 导出、剪贴板计划、止盈止损提醒创建和去重。
- 八个新工具均可保存，刷新后恢复仓位的结构化参数。
