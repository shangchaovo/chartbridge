# 行情与局域网

公开行情不需要 TradingView 或券商账户。价格不会用模拟数据补齐。国内期货账户桥默认关闭。

## 启动

1. 在项目目录执行 `npm start`，或使用本机启动器。页面是 http://127.0.0.1:18765/ 。
2. 只在需要给同一私网的其他设备使用时，才用局域网启动方式。
3. 与主机同一 Tailscale tailnet 的设备免凭据：打开 https://shang.tailc2493b.ts.net:18443/ （tailscale serve 反代，仅 tailnet 可达）或 http://<主机 tailnet IP>:18765/ ，即以 owner 身份使用；MCP 同理可用 `https://shang.tailc2493b.ts.net:18443/mcp` 且省去 Authorization 头。
4. 不在 tailnet 里的局域网设备仍需凭据：在主机页面打开「协作与 Agent → 局域网连接凭据」，输入只读或编辑凭据。这是本终端的访问凭据，不是交易所账户。不要把凭据放进 URL。

## 行情如何更新

- **Binance 现货**：官方免密钥 WebSocket，订阅 ticker 和对应周期 K 线，保留源事件时间和 K 线收盘标记。
- **OKX / Kraken 现货**：对应交易所的公开 REST 与 WebSocket。没有密钥，也不生成价格。
- **A 股**：新浪公开报价与原生分钟、日线。周线仍用有延迟的 Yahoo。
- **港股、外汇**：新浪公开报价，历史图表用 Yahoo。两个来源分开显示。
- **美股、国际期货与指数**：Yahoo 历史和公开快照。查看源延迟和报价时间。

连续期货代码可能换月。公开网页轮询不是交易所级零延迟推送。

## 共享图表

标的、周期、图表类型、指标及参数、画线、Pine 源码和批注通过共享图表实时同步。颜色与最近颜色、收藏工具图标及顺序、默认仓位参数、快捷键、图表设置、主题、自选、提醒、脚本、导入数据和面板布局也支持同步。

首次启用时，在 **MacBook 的映射页面**刷新，点击顶部带文字的「多端同步」，选择「首次从此终端导入配置」。这只负责把 MacBook 浏览器现有配置作为起点导入。其他终端首次更新也需要刷新一次，此后所有编辑终端平等，任意一端的修改都会通过实时推送同步到其余终端，断线重连后补齐。「图表设置」也保留同一入口。

配置保存在主机 `data/workspace.sqlite` 的事务中。只提交实际改动的项目，旧页面的整份工作区自动保存不能覆盖已经同步的设置。同一配置按服务器最后收到并成功保存的修改覆盖，不赋予首次导入的 MacBook 后续优先权。请求使用持久化批次回执去重，避免保存成功后丢失响应、重试又覆盖后来修改的情况。只读终端接收更新。面板在各设备按屏幕大小约束显示，不把小屏幕的自动收缩写回配置。登录凭据、编辑者标识和未完成的绘图操作不在配置同步范围内。

每批修改带读取时的 `baseRevision` 和唯一 `batchId`。版本冲突时保留本地草稿，不强制覆盖。

MCP 地址是 `http://<主机>/mcp`，请求头为 `Authorization: Bearer <凭据>`。参数和限制见 [Agent 计算与共享图表](agent-research.md)。

## 本机数据

`data/` 不进入 Git。其中有共享图表数据库、局域网凭据、个人工作区和行情缓存。备份前先停止服务，再复制这个目录。
