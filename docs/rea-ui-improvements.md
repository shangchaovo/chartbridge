# REA 公开界面对照与功能补齐（2026-10-17）

使用固定版本 `rea-agents 6.5.0` 在 Windows 独立临时 Chromium 中重新打开匿名 TradingView 图表，并依次展开线条、斐波那契、预测与测量、几何图形、文字五组菜单。全部场景步骤完成，浏览器由 REA 清理。公开观察摘要、证据 ID、逐步状态及菜单条目见 [rea-ui-coverage-2026-10-17.json](rea-ui-coverage-2026-10-17.json)；原始请求与记录保存在 `work/rea-ui-20261017/`。

功能分类同时参考 TradingView 的[官方绘图说明](https://www.tradingview.com/support/solutions/43000703396-drawing-tools-available-on-tradingview/)。本轮根据可观察交互，使用现有 KLineCharts 和自行编写的图形实现工作流。

## 本轮补齐

- **22 种绘图工具，五组菜单**：线段、射线、延长线、水平线/射线/线段、垂直线、十字线、平行/价格通道；斐波那契回撤与三点扩展；矩形、圆、三角形、箭头；文字、价格线、价格标签；价格、时间、时间与价格区间。每组保留上次选择，菜单支持方向键选择及 Esc 关闭。
- **完整绘图操作链**：普通/弱/强磁吸、连续绘图、全体锁定、临时隐藏、对象管理、逐个显隐/锁定/删除、定位、复制、颜色/粗细/实虚线、文字编辑。空白区和图形上的右键菜单提供常用操作。
- **撤销与重做**：每个品种和周期独立保留最近 80 次绘图修改；新增、删除、清空、移动、样式、文字、单个显隐和锁定均可撤销。收到改变图形内容的协作更新后重置该图表的本地历史，作者元数据回声不会清空历史。刷新后重新开始记录，避免撤销其他人的修改。
- **图表外观与导航**：线性/对数/百分比刻度、反转价格轴、网格、十字光标、最新价标记、水印、全屏、重置视图。外观设置保存在本机浏览器，应用于主图和对照图。
- **修复保存不完整**：工具清单与服务端绘图类型校验共用定义，补入此前被拒绝的 `localNote`；单个图形的显示状态随共享图表保存，临时“隐藏全部”只影响本机视图。未画完或按 Esc 取消的对象不会写入共享状态。
- **修复快速放置锚点**：KLineCharts 9.8.12 原始鼠标处理器会丢弃双击时间窗内、距离较远的第二次点击；也可能在切换工具后将同位置点击误判为结束绘图，留下无法恢复的单锚点图形。构建补丁让快速点击和绘图中的双击都正常放置锚点，非绘图状态的双击保持原行为。修改位置和原因见 `scripts/patch-klinecharts.mjs`，升级图表依赖时需重新核对补丁。

测量显示两点价格差、相对起点绝对价格的百分比、实际数据索引间隔及时间戳间隔；时间间隔不等同于交易日数。斐波那契扩展按第三点价格加前两点价差乘倍率计算，绘图坐标经当前价格轴转换。

## 验证与后续范围

自动化验证覆盖绘图历史、协作回声/远端变更、测量边界，以及所有工具类型的服务端保存和显示状态。浏览器验收在独立数据目录运行，使用现有真实历史缓存，验证鼠标绘图、快速锚点、保存、刷新恢复、撤销/重做、对象编辑和多尺寸布局；截图及执行记录在 `work/drawing-ui-check/`。

公开菜单观察不能建立全部算法等价性。本轮没有实现自由画笔、任意路径、完整 Gann/形态、完整仓位/成交量分布工具，也没有补齐完整 Pine 引擎或全部市场交易时段语义。这些缺口继续作为后续独立工作项，界面不提供无实现的占位工具。
